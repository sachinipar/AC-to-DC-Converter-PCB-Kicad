# AC to DC Converter PCB with KiCad

## Overview
This project demonstrates the design of an AC to DC Converter PCB using KiCad. It includes the complete workflow from schematic capture to PCB layout, footprint assignment, routing, and design verification.

The PCB is designed as a learning project to gain practical experience in PCB design and electronic hardware development.

## Features
- AC to DC power conversion
- KiCad schematic design
- PCB layout and routing
- Through-hole components
- Footprint assignment
- Design Rule Check (DRC)
- Fabrication-ready PCB

## Software
- KiCad

- PCB Routing

- Hardware Design
